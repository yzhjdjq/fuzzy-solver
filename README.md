# Решатель задач на нечёткой логике
Приложение с графическим пользовательским интерфейсом UI для решения задач \
на основе нечёткой логики.

#### Статус проекта
Основной функционал до стадии минимальной рабочей версии находится в процессе \
реализации в рамках курсового проекта по дисциплине "нечёткие множества и \
нейронные сети".

## Основные возможности
 - Задание неограниченное количества входных и выходных лингвистических переменных
 - Задание неограниченного количества термов для лингвистических переменных
 - Задание до 10 правил с поддержкой сложных условий и выводов до 3 элементов

## Инструменты разработки и поддерживаемые платформы
Для разработки применяется `python` и `PySide6`. Для реализации интерфейса \
применяется декларативный подход с `QtQuick2`. Основываясь на этом стеке, \
можно утверждать, что поддерживаются следующие платформы:
 - Windows
 - Linux
 
Готовые исполняемые файлы не распространяются, поэтому основным условием \
запуска является наличие интерпритатора python и окружения, поддерживающего \
работу Qt-интерфейса.
